# Bootstrap Web Stack Project
This project consists of a series of HTML files (1-index.html to 6-index.html) that demonstrate the use of Bootstrap 4 to create responsive web pages. Each file builds upon the previous one, introducing new features and custom styles.

## Files Overview
File Name	Description
### 1-index.html	
- Basic HTML structure with no Bootstrap styling.
### 2-index.html	
- Introduces Bootstrap classes for basic layout and styling.
### 3-index.html	
- Adds a responsive navigation bar and grid system.
### 4-index.html	
- Implements cards and buttons with Bootstrap classes.
### 5-index.html	
- Adds a modal and customizes button behavior.
### 6-index.html	
- Final version with custom styles (6-styles.css) applied to buttons, links, cards, and text.
## Features
**Responsive Design:**  All pages are optimized for different screen sizes using Bootstrap's grid system and utility classes.

**Custom Styles:** The 6-styles.css file overrides default Bootstrap styles to meet specific design requirements.

**Interactive Components:** Includes buttons, cards, modals, and navigation bars.

## Requirements
**HTML Structure:** Do not modify the existing HTML structure in any file.

**Custom Styles:** All custom styles must be defined in the 6-styles.css file.

**No Inline Styles:** Avoid using inline styles or 
## Custom Style tags in the HTML.

- Custom Styles (6-styles.css)
The 6-styles.css file includes the following customizations:

- Buttons
```.btn-primary```: Background and border color set to #E0003C.

```.btn-primary:hover```, .btn-primary:focus, .btn-primary:active: Background and border color set to #BC1340.

.btn-outline-primary: Text and border color set to #E0003C.

.btn-outline-primary:hover, .btn-outline-primary:focus, .btn-outline-primary:active: Background and border color set to #E0003C, text color set to white.

Links
a: Text color set to #E0003C for all links.

a:hover, a:focus: Text color remains #E0003C.

Cards
.card: Border color set to #E0003C and border radius set to 1rem.

.card-header, .card-footer: Border color set to #E0003C.

Muted Text
.text-muted: Text color set to #8C8C8C.

How to Use
Clone the repository or download the project files.

Open each HTML file (1-index.html to 6-index.html) in a web browser to view the progression of the project.

Customize the 6-styles.css file to further modify the design as needed.

Dependencies
Bootstrap 4: The project uses Bootstrap's CSS and JavaScript files via CDN.

Fonts: Uses default Bootstrap fonts.
